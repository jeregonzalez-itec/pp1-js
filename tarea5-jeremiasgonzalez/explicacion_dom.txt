# PATRÓN PARA WEB APPS

# Obtener datos

```js
getProducts()
```

# Guardar datos

```js
listaProductos = datos
```

# Renderizar

```js
renderProducts(listaProductos)
```

# Buscar

```js
const filtrados = listaProductos.filter(...)
```

# Volver a renderizar

```js
renderProducts(filtrados)
```

# E-COMMERCE BÁSICO

Productos:

```js
let listaProductos = []
```

Carrito:

```js
let listaCarrito = []
```

Agregar producto:

```js
listaCarrito.push(producto)
```

Buscar producto:

```js
const producto = listaProductos.find(...)
```

Mostrar carrito:

```js
renderProducts(listaCarrito)
```

Eliminar producto:

```js
listaCarrito.splice(indice, 1)
```

Actualizar pantalla:

```js
renderProducts(listaCarrito)
```
